# Case-Insensitive-Login-TShock-Plugin
Allows players to login by typing their username case-insensitively. Also implements /userlist, a SuperAdmin command that shows a list of all usernames currently in the database

i.e.

`/login SuperMario password`

is equal to

`/login supermario password`

and again equal to

`/login SUPERMARIO password`

---

`/userlist` would print something like:

`Found 10 registered user(s) in the database:`

`BARZOTTO, BioNick, Brubano, Lollo9, Maestro, MariettoRapper, Schifo, dab, lollo9, sini`

------
## INSTALLATION:
Just drop the `CaseInsensitiveLogin.dll` from the Releases tab to your ServerPlugins directory and restart TShock
